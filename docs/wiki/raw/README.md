# Raw Inbox

This directory is a local, Git-ignored inbox for safe source material awaiting summarization into the wiki. Only this guide is tracked.

Allowed examples include public documentation excerpts, non-sensitive research notes, and temporary copies of public articles. Confirm that material is lawful to retain and appropriate for the repository workspace.

Never add `.env` files, credentials, tokens, private keys, service-account files, real tickets or grievances, private student data, personally identifiable information, unredacted logs, production payloads, or support exports.

After processing a safe item, create or update concise linked pages under `docs/wiki/`, record a material change in [[log]], and remove the local raw item when it is no longer needed.
